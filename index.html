Nights Publisher

Nights Publisher is a private publishing tool for the YouTube channel Nights of Mythology. It uploads the channel's own finished videos, thumbnails and subtitles and schedules them with the YouTube Data API.

It has a single user (the channel owner), runs only on the owner's computer and stores no user data.
